
# AI-Powered QA Testing Assistant

## Project Overview
This project is a beginner-friendly web application designed to help manual QA testers generate test scenario ideas, prepare bug report drafts and create prompts for AI-assisted testing.

## Features
- Requirement-based test scenario suggestions
- Bug report draft generator
- ChatGPT prompt builder
- CSV export for test cases
- Text-file export for bug reports

## Technologies Used
- HTML
- CSS
- JavaScript
- ChatGPT for separate AI-assisted test case generation

## How to Run
1. Download or clone the project folder.
2. Open `index.html` in a web browser.
3. Enter a feature and its requirements.
4. Generate test cases or prepare a bug report.
5. Use the Prompt Builder to create a prompt for ChatGPT.

## Current Limitations
The website currently uses predefined templates and keyword-based rules. It is not directly connected to a live AI model or API. ChatGPT is used separately for AI-generated test cases.

## Future Improvements
- Secure integration with a live AI model
- More detailed test case generation
- Test execution and result tracking
- Additional export options
